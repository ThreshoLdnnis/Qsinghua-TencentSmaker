# 外星旅伴世界观与前端演示边界

翎语的主产品不是一个没有身份的聊天窗口，而是一组可以在日常支持中逐渐认识的 Personal Agent。每位旅伴来自一颗未知星球，拥有自己的名字、家庭、学校、社会和价值观。用户先通过故事理解这位朋友如何看待“失败、需要、节奏和下一步”，再决定是否邀请他进入对话。

## 当前演示

`frontend/src/components/companion-world.tsx` 提供三位合成旅伴：

- 拾光 / 云岚星：先理解，再行动；留白也是答案；小一步也算向前。
- 未蓝 / 弦月环：需要可以被说出；失败不等于身份；给自己第二种解释。
- 栖雨 / 潮汐森：数字只做线索；感受由自己命名；照顾先于证明。

用户可以切换旅伴、浏览家庭/学校/社会故事，并点击“邀请降临”。`lovestone.tsx` 会把旅伴的开场句填入对话输入框，随后仍沿用原有的“输入 → 可修改理解 → 用户确认/纠正 → Keep / Release / Next → 经历卡”流程。

## 产品边界

故事用于提供共同语言、示范另一种解释和邀请一小步行动。旅伴不替用户下诊断，不把自己的价值观强行写入用户记忆，也不把可穿戴信号当作心理结论。AI 的事实、解释、情绪和需要始终是可修改、待确认的假设。

当前旅伴资料和故事是前端合成演示，刷新后清除；真实模型上下文、角色长期记忆、账号隔离后的授权关系和 Personalization & Evaluation Engine 尚未由本模块声称完成。接入后端时，必须分别记录角色设定、用户主动保存的经历卡、当轮参考授权和纠正版本，并在撤回授权后使旧上下文失效。
